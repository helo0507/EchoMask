# EchoMask
Voiceprints are widely used but easily captured. Existing device-level systems fail on untrusted microphones. EchoMask anonymizes voiceprints in real time using acoustic metamaterials, combining frequency-selective interference, acoustic-field modeling, and reconfigurable structures to preserve intelligibility and prevent pattern learning.

We have provided 3D design files for the metamaterial system in the repository, including two types of drawings suitable for traditional microphones and mobile device microphones. Please note during use: The metamaterial must fully and tightly wrap the microphone without any gaps, as gaps will weaken the interference effect. If gaps are present, materials such as acoustic foam can be used to fill and seal them.
